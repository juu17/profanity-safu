# Changelog

Notable events and changes for Profanity SAFU, newest first.

## 2025-12-08

All addresses generated by this tool have been spared from exhaustive attacks in the production environment over the past three years. Several institutions managing millions in EVM assets adopted it after rigorous code review.

## 2022-11-15

Vulnerabilities were fixed by Juu17. Any suggestions are welcome!

> **Attention!** Do NOT run the release binary on **Windows**: there is no built-in entropy pool for getting random-enough numbers. The key random-number generator `std::random_device` falls back to a pseudorandom source on some Windows toolchains, which brings vulnerable private keys in front of you. See the Security section of the [README](README.md).

## 2022-09-15

All affected binaries have been removed to prevent further unsafe use of this tool. See the following article for more information:

https://blog.1inch.io/a-vulnerability-disclosed-in-profanity-an-ethereum-vanity-address-tool-68ed7455fc8c

## 2022-09-15

As per [issue 76](https://github.com/johguse/profanity/issues/76), the original repository was archived to reduce the risk that someone uses the flawed tool. The upstream code receives no updates and was left in an uncompilable state.
